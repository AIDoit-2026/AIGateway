# 版本历史

## 2.1.0 - 2026-08-04

- 完善上游失败日志，记录真实请求 URL、HTTP 方法和请求头，不再使用站点 URL 与模型名拼接虚假地址。
- 增强 Responses/Chat endpoint 流程的失败上下文传递，便于定位 `/v1/responses` 等实际请求路径。
- 补充日志回归测试和任务清单状态，提升上游 502、超时及 endpoint fallback 问题的诊断能力。

## 2.0.2 - 2026-07-06

- 新增下游密钥公开用量页，可通过 `/public/downstream-keys/:id/usage` 无登录查看单个下游密钥统计面板。
- 管理端下游密钥列表新增公开用量地址复制和打开统计面板操作。
- 公开接口仅返回统计展示字段，不暴露完整密钥、路由策略、站点权重和排除凭证引用。

## 2.0.1 - 2026-07-02

- 代理日志增加请求 IP 记录，便于排查下游调用来源。
- 使用日志列表和详情展示客户端 IP。
- 新增 `client_ip` 数据库字段及 SQLite / MySQL / PostgreSQL schema 产物。
- 新增 Docker 镜像构建脚本 `scripts/docker-build.sh`，默认生成当前版本标签和 `latest` 标签。

## 2.0.0 - 2026-06-28

- 项目正式更名为 AIGateway。
- 连接管理精简为 API Key only 主路径，移除客户端侧账号登录、账号令牌、签到记录和 OAuth 管理入口。
- 保留历史数据结构和部分后端兼容能力，避免旧数据因 UI 精简被自动删除。
- API Key 连接在代理失败时不再自动置为 `expired`，失败只影响通道健康和告警。
- 增加低延迟代理模式，将代理日志、成本统计、调试追踪等非必要工作转为可跳过或后台执行。
- 更新入门、配置、上游接入、管理 API、FAQ 等文档，统一引导使用 Base URL + API Key 接入。
